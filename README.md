# SMIU Student Attendance & Resource Portal

A centralized web-based solution developed to streamline academic workflows, schedule management, and attendance tracking for the BS AI department at Sindh Madressatul Islam University.

## 🚀 Key Features
- **Centralized Dashboard:** One-stop access for daily class schedules and enrollment codes.
- **Resource Integration:** Synced with Google Drive for real-time academic file updates.
- **Responsive UI:** Logic-driven frontend optimized for both mobile and desktop users.
- **AI-Accelerated Development:** Leveraged prompt engineering and AI tools for rapid prototyping and deployment.

## 🛠️ Tech Stack
- **Frontend:** JavaScript (ES6+), HTML5, CSS3
- **Deployment:** Firebase / Web Hosting
- **Integration:** Google Drive API

## 📈 Impact
Currently serving as the primary information hub for the BS AI (Section 3B/4B) student body, significantly reducing the friction of finding scattered academic data.
